When Claude picks up a skill called deal-sourcing, it can sound as if Claude has gained the ability to judge which companies are worth investing in. The video says it has not. The skill finds candidates, and whether any of them is a good deal remains up to the person using it.

## The tempting assumption

The framing the video starts from is that a deal-sourcing skill means Claude now decides where to invest. It sounds like investment judgment. But nothing in the model changes when a skill is added.

The video makes this concrete with a thought experiment: delete the skills folder, and Claude does not lose any investment judgment, because there was none to begin with. It only stops running a three-step checklist.

## What a skill actually is

A skill is a folder holding a single file, SKILL.md. For deal-sourcing, that file lists three steps in order:

1. Search a sector for target companies.
2. Check the CRM for existing relationships.
3. Draft a personalized outreach email to the founder.

Claude reads the file top to bottom and works through it step by step. There is no branching unless the file itself says to branch.

## A specification, not new judgment

This makes a skill a specification. The payoff is that the same three steps run for every sector, every time. The limit is that ranking candidates by how good an investment they are is not on the page, so Claude is not told to do it. Each time the skill runs, Claude reads the same file and works through the same steps. The video calls that the whole trick.

## Why the output proves little on its own

The video also warns against treating results as evidence. Watching Claude surface twenty candidate companies shows only that the search step ran. It says nothing about whether any of them is a good investment. Likewise, watching Claude draft a clean, personalized outreach email shows nothing about whether the founder will ever reply. A skill named deal-sourcing does not hand Claude investment judgment. It finds candidate companies and drafts the outreach.

## Key takeaways

- A skill is a folder with one SKILL.md file that Claude reads before and while it works.
- Deal-sourcing has three steps: search a sector, check the CRM, draft a founder outreach email.
- Deleting the folder removes the checklist, not any investment judgment.
- Claude follows the steps in order, without branching unless the file says so.
- The payoff is the same process every sector, every run.
- Ranking candidates by investment quality is not in the file.
- Twenty candidates or a polished email prove nothing about deal quality.

## Try it yourself

Pick one repeatable search-and-outreach routine you run over and over. It can be about sourcing candidates for anything, not only deals. Ask Claude to write you a SKILL.md for it, with the steps in order and in plain language. Then have Claude read it back and walk you through exactly what it will do before it does it.
