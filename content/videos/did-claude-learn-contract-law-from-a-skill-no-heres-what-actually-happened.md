It is easy to assume that Claude learned contract law from a skill called material-contract-schedule. The video says it did not. Claude was handed a file of instructions, and material-contract-schedule is simply the name of one such file. The rest of the episode, from the Claude Basics series, explains what is actually inside it.

## Why the name misleads

The skill sounds like a deal-review upgrade, as if Claude had studied M&A contracts and come back knowing something it did not know before. The video points out that nothing in the model changes. A simple test shows it: delete the skill's folder, and Claude does not forget any contract law, because there was nothing to learn. It just stops following that one routine.

## What a skill actually is

A skill is a folder, and in this case the folder holds a single file called SKILL.md. The file contains instructions, written in plain language, for turning a stack of contracts into a structured disclosure schedule. Claude reads it before it starts.

## How Claude uses the file

Claude reads the file from top to bottom and works through it step by step, in the order it is written. There is no branching unless the file itself says to branch. That is why the video calls a skill a specification, not a new power.

## The payoff and the limit

The payoff is consistency: the same schedule structure every time, with one row per contract and the same columns filled in. The limit is that anything outside those written steps leaves Claude off the map. So the skill never taught Claude how to judge a contract. It guarantees only that each time the skill runs, Claude reads the same file and produces the same schedule structure.

## Neither outcome proves anything on its own

The video then reads the result in both directions:

- A schedule with every row filled in does not prove every contract was actually checked against the file's criteria, because a cell can be filled in without a fact behind it.
- A schedule with gaps does not prove the skill is broken, because it may simply mean the file asked for something the contracts never said.

A skill does not teach Claude what counts as a material contract. It is a file of steps Claude reads before it starts, so the schedule comes out in the same shape each time.

- A skill called material-contract-schedule does not give Claude new legal knowledge.
