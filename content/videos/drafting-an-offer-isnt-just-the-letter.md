## More than a congratulatory letter

The video starts from a common assumption: asking Claude to help with an offer means asking it to write the letter. The video corrects that. A complete offer, as this skill defines it, includes the compensation package of base pay, equity and a signing bonus, the letter text, and guidance for the hiring manager.

## A skill is a folder Claude reads first

This kind of drafting is built from something called a skill. A skill is a folder that Claude reads before it works. Inside is one file written in plain language that spells out exactly what counts as a finished offer. Claude reads the file and then follows it. The video says the file is the whole program.

## How the steps run

The steps run in order. Claude reads the file, works through each step exactly as written, and then returns the result. Nothing runs out of sequence unless a step itself says it should. This is why the skill behaves predictably: what it produces depends on what is written in the file.

For this skill there are exactly three things it covers, once a candidate is ready for an offer:
