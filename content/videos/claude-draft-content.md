## A skill is a file Claude reads

The video defines a Claude skill as a folder Claude reads before it works. For this one, the SKILL.md file holds the entire instruction set in plain language, with nothing hidden. Claude reads the file and then acts. The video puts it this way: the file is the program.

## How Claude runs it

The instructions live in a steps section. Claude reads each step in order and runs it from start to finish. There is no branching unless a step says otherwise. This makes the skill predictable, because the sequence of actions is written down in advance.

## The one job: marketing content for specific channels

Draft-content has one job. It drafts marketing content with channel-specific formatting and SEO recommendations attached. The video lists the kinds of content it covers:

- blog posts
- social media
- email newsletters
- landing pages
- press releases
- case studies

## Three moments the skill is written for

The file is written for three situations: writing any marketing content, generating headline or subject-line options, and adapting a message for a specific platform, audience and brand voice. Outside those three moments, the video says the file has nothing to say. That scope is the point of the lesson. A skill is not a new writing talent; it is one file doing one job.
